# Лабораторная работа №2. Целочисленная арифметика

Мы продолжаем изучать и работать с базовыми понятиями языка C++: переменные, условия, циклы. В данной лабораторной работе вам предстоит поработать с их более сложным взаимодействием.

Текст с заданием находится в текущей директории в файле [task_lab2.md](./task_lab2.md). 

**Номер варианта**: $(N - 1)\mod 14 + 1$, где $N$ – ваш порядковый номер в подгруппе.

> Также в этой лабораторной работе есть дополнительные задачки, в которых вам нужно будет найти "уязвимость" в коде и сделать так, чтобы программа завершилась с ненулевым кодом (см. файл [task_lab2.md](./task_lab2.md/#дополнительные-задания)). Советую попробовать их порешать.
